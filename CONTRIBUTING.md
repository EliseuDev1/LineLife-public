# Contribuindo

Este snapshot não oferece suporte ao usuário, consultoria de implementação, manutenção ou promessa de incorporação de alterações.

Cada interessado é responsável por:

- compreender o código;
- preparar o próprio ambiente;
- reproduzir a instalação e os testes por conta própria;
- avaliar compatibilidade, segurança e adequação ao seu uso;
- usar dados fictícios, sem informações pessoais ou credenciais.

Não envie tokens, licenças, arquivos `.lvd` reais, logs com dados pessoais ou artefatos de produção.
